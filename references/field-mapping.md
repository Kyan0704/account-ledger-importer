# 账号台账字段映射参考

从注册/登录截图中提取信息时，按以下常见字段名进行映射。目标表的实际字段以 `+field-list` 返回为准，此处仅作提取和默认值参考。

## 常见字段映射

| 目标字段（常见命名） | 从截图提取 | 无信息时默认值 | 字段类型 |
|---|---|---|---|
| 平台名称 / 平台 / 网站 | 页面标题、Logo、品牌名（如"模课""微信""支付宝"） | 必须提取，不留空 | text |
| 账号/用户名 / 用户名 / 账号 | 展示名称、用户名、自定义登录账号、邮箱前缀 | 必须提取，不留空 | text |
| 登录密码 / 密码 | 密码输入框明文（点击眼睛图标后） | 必须提取，不留空 | text |
| 绑定手机号 / 手机号 | 已验证手机号（通常带星号脱敏） | 留空 | text |
| 绑定邮箱 / 邮箱 | 邮箱输入框内容 | 留空 | text |
| 会员类型 / 会员等级 | 页面显示的会员标识；刚注册未付费则为免费 | "免费" | select |
| 开通时间 / 注册时间 / 创建时间 | 截图时间或当前日期 | 当前日期 YYYY-MM-DD 00:00:00 | datetime |
| 到期时间 / 有效期至 | 页面显示的到期日期；免费账号通常无到期 | 留空（免费账号） | datetime |
| 付费金额 / 金额 / 价格 | 订单金额、支付金额 | 0（免费注册） | number/currency |
| 自动续费 / 自动续订 | 开关状态或协议勾选 | "否" | select |
| 账号状态 / 状态 | 正常注册则为正常使用 | "正常使用" | select |
| 备注 / 截图 / 附件 | 原始截图上传为附件 | 上传截图 | attachment |

## 单选字段常见选项

写入 select 字段前必须用 `+field-list` 确认目标表已有选项，以下为常见约定值：

- **会员类型**：免费、普通会员、高级会员、年度会员、终身会员、付费增值
- **账号状态**：正常使用、已注销、闲置、冻结、已过期
- **自动续费**：是、否

## 只读字段（禁止写入）

以下字段由系统自动生成，写入时必须排除：
- auto_number（如台账ID、编号）
- formula（如剩余天数、是否过期、会员状态分类）
- created_at / updated_at（如最后更新时间）
- created_by / updated_by

## 派生字段计算规则

- **开通时间**：使用当前日期，格式 `YYYY-MM-DD HH:mm:ss`
- **付费金额**：免费注册填 0；有付费信息时填实际金额
- **会员类型**：截图无付费信息时默认"免费"；有会员标识时按实际填写
- **到期时间**：仅在截图明确显示到期日期时填写，免费账号留空
