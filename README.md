# account-ledger-importer

> 从账号注册/登录截图中自动提取平台名称、用户名、密码、手机号等信息，并录入飞书多维表格（账号台账）。支持图片信息提取、Base 表结构解析、字段映射、记录创建、截图附件上传、回读验证全流程。

## 技能简介

- **技能名**：`account-ledger-importer`
- **功能**：分析账号注册/登录页面截图，自动提取账号信息并写入飞书多维表格，同时上传原始截图作为附件，最后回读验证。
- **适用场景**：批量管理各平台账号密码，需要将注册截图结构化存储到多维表格中以便后续查找。

## 使用前配置

本技能不绑定任何特定的多维表格，使用前需准备：

1. **创建账号台账表**：在飞书中新建多维表格，包含平台名称、账号/用户名、登录密码、绑定手机号、会员类型、开通时间等字段。字段名可自定义。
2. **获取表格链接**：复制多维表格的浏览器 URL（格式如 `https://xxx.feishu.cn/base/xxxxxxxx`）。
3. **提供给 AI**：使用时将截图和你的多维表格 URL 一起发给 AI，技能会自动解析并写入。
4. **依赖**：需已安装并登录 `lark-cli`（飞书命令行工具），且对目标表格有编辑权限。

## 使用说明

完整工作流见 [SKILL.md](SKILL.md)。典型流程：

1. 分析截图提取账号信息

5. 上传原始截图为附件
